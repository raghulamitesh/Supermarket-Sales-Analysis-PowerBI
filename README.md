# Supermarket Sales Dashboard – Power BI

## Project Overview
An interactive supermarket sales dashboard developed using Microsoft Power BI to analyze sales-related data and visualize key business metrics.

## Key Performance Indicators (KPIs)
- Total Quantity
- Total Tax
- Total Invoice
- Average Unit Price

## Tools & Technologies
- Microsoft Power BI
- Power Query (if used)
- DAX (if used)

## Project Objective
To transform supermarket sales data into meaningful visual insights through interactive dashboards and KPI analysis.
